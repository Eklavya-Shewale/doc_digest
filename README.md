# DocDigest

DocDigest is a Spring Boot application that allows users to securely upload, organize, search, and manage PDF documents.

The project is being built as a learning project while following production-style backend development practices.

---

## Features

### Current
- Spring Boot project setup

### Planned
- User Authentication (JWT)
- PDF Upload
- Document Management
- Search
- Pagination & Sorting
- PDF Text Extraction
- AI-powered Document Summaries
- Flashcard Generation
- React Frontend

---

## Tech Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- Maven
